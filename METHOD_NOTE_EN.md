# Research-agent benchmark: six development calls for weighted RRF

This repository turns a small information-retrieval optimization problem into an inspectable agent task. An agent proposes `k` and the BM25 weight for weighted reciprocal rank fusion, records a hypothesis **before** each of at most six development-set evaluations, and commits to the best observed development candidate. A separate supervisor evaluates that frozen choice against public NFCorpus test labels. The primary metric uses exponential relevance gain, `2^rel - 1`, for nDCG@10.

The result is negative. Three additional six-call LLM trajectories independently selected the same candidate, `k=100` and BM25 weight `0.5`. That candidate scored **0.307044** on the 323-query public test split, below the pre-specified six-point search at **0.307294**. Since all three choices produce one identical ranking, they provide one unique test outcome, not three independent generalization results. A 189-point grid and 100 six-call random-search simulations are numerical comparisons, not additional LLM agents. One earlier six-call trajectory scored 0.308875; its paired-query bootstrap interval against the preset search included zero.

The public test landscape was inspected during the wider exploratory study. This work does not claim blinded generalization, agent superiority, full-paper reproduction, or unaided applicant authorship. AI tools assisted implementation, execution and analysis. The defensible contribution is the bounded task protocol, preserved agent decisions, explicit comparison budgets, and a reproducible negative result.

The repository excludes third-party NFCorpus text, qrels and derived full ranking caches. Run `python3 verify_public_traces.py` for a data-free integrity check. For numerical reproduction, follow the pinned upstream download and cache rebuild commands in the [main README](README.md#从上游数据重建和复核).
