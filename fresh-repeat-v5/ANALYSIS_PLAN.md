# Fresh-context 六次预算轨迹：公开测试前的分析计划

本计划在第三条轨迹完成前写入。历史代理与 v4 网格的公开 test 结果已经被主线程看过，因此本次属于**探索性补实验**，不能称为完全盲测。三个新代理各用独立空白上下文，只见各自的开发缓存和工具反馈；同一模型家族、相同任务说明与评价器会限制轨迹独立性。

1. 每条轨迹最多六次、15 分钟。冻结本目录 `state.json`、六个候选、六个先行假设及工具结果的 SHA。状态完整、输入哈希相符、候选互异才可纳入。
2. 仅按各自开发集指数增益 nDCG@10 选最高，平分取最早轮次。全部三条轨迹的选择冻结后才调用公开 test；不根据 test 更换候选或追加调用。
3. 用冻结的完整稳定排序评价器计算每条选择在公开 test 的指数和线性增益 nDCG@10；保留每查询分数。重复相同配置时仍记录为独立代理决策，但不把相同配置当独立模型或独立测试样本。
4. 与既有历史代理、预设六点搜索及 v4 的 100 组随机搜索作描述比较。重点报告三条轨迹的选择分布、开发和测试分数及是否超出随机搜索经验位置，不用单一最高分主张代理优势。公开 test 已用于 v4 事后参数扫描，新增结果同样按探索性解释。
5. 成功次数、失败或超时原样报告。不得把空白、脚本模拟或随机搜索写成 LLM 轨迹；不得把主线程 AI 辅助执行写成申请人亲自完成的研究操作。

环境：`gpt-5.6-terra`、`medium`、`fork_turns=none`；固定 NFCorpus 开发缓存，Python 3.13。分析代码在本目录新建，冻结输入不改写。任何发现的评价器错误应先停下、保留原始日志并单独修订，不覆盖已有结果。
