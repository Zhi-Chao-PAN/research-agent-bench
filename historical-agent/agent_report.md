# NFCorpus 开发集参数优化报告

本次仅完成一次六轮开发集优化；选择依据为观测到的开发 nDCG@10，不涉及测试集或泛化结论。

| 轮次 | 先行假设 | 参数（k，BM25权重） | 开发 nDCG@10 | 下一步/结果 |
|---:|---|---:|---:|---|
| 1 | 以中等融合深度和等权建立参考。 | 60, 0.50 | 0.2651036767543689 | 建立参考，测试更高 BM25 权重。 |
| 2 | 保持深度并上调 BM25，检验词项匹配贡献。 | 60, 0.75 | 0.2647023239282857 | 低于参考，转测偏 TF-IDF。 |
| 3 | 高 BM25 略降，改测偏 TF-IDF 确认权重方向。 | 60, 0.25 | 0.26003365976972265 | 明显低于参考，保留等权并测试较小 k。 |
| 4 | 减小 k 以强调排序头部结果。 | 20, 0.50 | 0.2647725364953930 | 略低于参考，改测更大 k。 |
| 5 | 增大 k 以检验平滑的深排名贡献。 | 120, 0.50 | 0.2649429998281612 | 仍低于参考，回到 k=60 作局部权重微调。 |
| 6 | 高 BM25 的大幅偏移降幅较小，微幅上调或有收益。 | 60, 0.55 | 0.2651113228826503 | 本轮为最高开发 nDCG@10，选定。 |

负结果显示，在 k=60 下，将 BM25 权重改为 0.25 或 0.75 都低于等权参考；在等权下，k=20 和 k=120 也低于 k=60。开发集可见的最高值为试验6的 0.2651113228826503，故 `final_choice.json` 选择试验6。限制：仅有六次固定开发评估，未访问或推断测试成绩，不能据此声称测试或泛化表现。
